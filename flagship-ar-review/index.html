Before you start

Run the placement and lighting test first. It takes two minutes, and it decides how the rest should be built.

Phone session protocol

  1. Tap to visible — start a screen recording, tap, stop when the dish is on the table. Only a recording measures this; nothing on the page can.
  2. First appearance — too close, too large, or right?
  3. Approach — seated, then a hand's width away, then closer. Does it get more convincing, or does the trick show?
  4. Rim and behind — torn edges, floating bits, holes.
  5. Ruler — hold a ruler beside the plate. Close enough to the size on the dish's page? That is what turns PROBABLE into VERIFIED.
