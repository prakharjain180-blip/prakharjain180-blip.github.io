Two pages, the same model file, one difference between them. Open each in Safari on the iPhone and record whether it lets you pinch the dish to a different size.

TEST A — lock on the link carries #allowsContentScaling=0 · should NOT resize TEST B — lock off no fragment, the control · SHOULD resize

A refuses and B allows → the fragment works, and VistARa's own integration is what to fix.
Both allow → the fragment is not honoured on this iOS build; it is a platform limit.
Neither opens the camera → the link is not being recognised as an AR link.
